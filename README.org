#+TITLE: mongodb.el

=mongodb.el= is a pure Emacs Lisp MongoDB wire protocol client.

It speaks BSON and MongoDB =OP_MSG= directly.  It is a command-level client,
not a JavaScript evaluator, JDBC bridge, SQL interface, or GUI/query-console
package.

* Status

This package intentionally keeps a small native surface for applications such
as Clutch.

Supported:

- BSON encode/decode and explicit BSON wrapper values.  Decoding and
  encoding are inverse operations: arrays decode to vectors, empty
  embedded documents to the =mongodb-document= wrapper, null to =nil=,
  false to =:false=, non-finite doubles and the non-scalar BSON types to
  Extended JSON tagged alists such as =(("$oid" . "…"))=, and the
  encoder maps every one of those shapes back to the BSON type it came
  from, so any decoded value can be written back unchanged.  Operator
  documents such as =$set= or =$gt= are not type tags and encode as
  plain documents.
- bounded direct TCP connections, optional TLS, =mongodb://= URLs, and plist
  params
- certificate and hostname verification for TLS by default; use
  =:tls-verify nil= only for explicitly insecure endpoints
- SCRAM-SHA-256 and SCRAM-SHA-1 authentication
- OP_MSG command execution and cursor =getMore= / =killCursors=
- helpers for find, aggregate, count, distinct, insert, update, delete,
  collection/index metadata, create/drop collection/index, explain, and drop
  database

Out of scope for now:

- =mongodb+srv=, seed-list discovery, SDAM, pooling, sessions, transactions,
  retryable reads/writes, compression, load-balanced mode
- X.509, PLAIN, AWS, OIDC, client-side encryption, change streams, bulkWrite
- MongoDB Shell JavaScript, SQL, JDBC, ODBC, BI Connector, or GUI behavior

* Usage

#+begin_src emacs-lisp
(require 'mongodb)

(let ((conn (mongodb-connect '(:url "mongodb://127.0.0.1:27017/app"))))
  (unwind-protect
      (mongodb-find conn "app" "users" '(("active" . t)))
    (mongodb-disconnect conn)))
#+end_src

Run arbitrary command documents with =mongodb-command=:

#+begin_src emacs-lisp
(mongodb-command conn "admin" '(("ping" . 1)))
#+end_src

Each connection executes one command at a time.  Response timeouts, malformed
wire frames, and transport failures close the connection so it cannot be reused
after protocol synchronization is lost.

Version 0.1.1 validates BSON document boundaries, UTF-8 and booleans strictly,
enforces negotiated write limits, bounds SCRAM work, and caps cursor helpers at
=mongodb-max-cursor-documents= (10,000 by default).  Plist connections may use
=:auth-database= as an alias for =:auth-source=.  Normalized connection metadata
is available through =mongodb-connection-host=, =mongodb-connection-port=, and
=mongodb-connection-username=.

Use explicit BSON wrappers when the wire type matters:

#+begin_src emacs-lisp
(mongodb-insert
 conn "app" "events"
 (list (list (cons "_id" (mongodb-new-object-id))
             (cons "createdAt" (mongodb-datetime 1704164645678))
             (cons "counter" (mongodb-int64 9223372036854775807)))))
#+end_src

* Tests

Run unit tests:

#+begin_src sh
emacs -Q --batch -L . -l ert -l test/mongodb-test.el \
  --eval '(ert-run-tests-batch-and-exit)'
#+end_src

Byte-compile:

#+begin_src sh
emacs -Q --batch -L . -f batch-byte-compile mongodb.el test/mongodb-test.el
#+end_src

For protocol changes, also run the live smoke test against a MongoDB server —
it inserts a document exercising every BSON type and asserts the stored copy
re-encodes byte-identically — and rerun the consuming Clutch MongoDB adapter
tests:

#+begin_src sh
MONGODB_TEST_URI=mongodb://127.0.0.1:27017/clutch_test \
  emacs -Q --batch -L . -l ert -l test/mongodb-test.el \
  --eval '(ert-run-tests-batch-and-exit)'
#+end_src
